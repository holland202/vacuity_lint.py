# E15 instrument decision — 2026-10-27

Status: **Decided: re-register. E15 v2 is REGISTERED, NOT RUN.**

This file records the owner's decision on the open question in
[DEVIATIONS.md](DEVIATIONS.md). Neither that file nor the original
[PREREG.md](PREREG.md) is edited.

## The question

The original registration pinned the scanner at `e549dbf` and forbade changing
it before results. The scanner was changed while E15 was unrun. Two options
remained: run the exact original instrument, or register E15 again on a newer
scanner.

## Decision

Re-register. The new registration is [PREREG_v2.md](PREREG_v2.md). It pins the
scanner at `b0db5ac` by sha256 and keeps every prediction, margin, seed,
sampling rule, exclusion rule and statistic of the original.

## Reasons

1. The changes since `e549dbf` move the primary outcome (verification-shaped
   files per repository), not only the findings. Known defects that affect
   that count are fixed in the newer scanner.
2. No E15 data has been drawn under either registration, so re-registering
   now loses no temporal protection: it is still a registration before data.
3. The original instrument is not discarded. It runs on the same trees as a
   descriptive instrument-sensitivity analysis, so any effect of the choice
   is visible instead of argued about.
4. The new freeze clause pins the scanner's bytes, not the repository file,
   so ongoing development on `main` cannot break the freeze again.

## What this costs

- The newer scanner has its own documented blind spot (VL-FP-003) and an
  unfixed false-alarm kind that inflates the primary outcome (kind C).
  Both are registered as limitations in PREREG_v2.md.
- The original registration, dated 2026-09-08, is superseded unrun. It stays
  in the repository as the historical record.
